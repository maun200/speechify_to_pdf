# Contributing

Thanks for your interest in improving speechify-to-pdf!

## How to contribute

- **Bug reports:** Open an issue and include your Python version, OS, and a description of what went wrong.
- **Feature requests:** Open an issue first to discuss before writing code.
- **Pull requests:** Fork the repo, make your changes, and open a PR against `main`.

## Development setup

```bash
git clone https://github.com/maun200/speechify_to_pdf.git
cd speechify_to_pdf
pip install pymupdf
```

## Code style

- Single-file architecture (`speechify_to_pdf.py`) — keep it that way unless there is a strong reason to split.
- Type hints on all public functions.
- No external dependencies beyond PyMuPDF.
